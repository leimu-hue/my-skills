# 通用规则

## 作者获取优先级

生成文档时，作者字段按以下优先级获取：
1. 当前用户：`$env:USERNAME` / `whoami`
2. Git 提交作者：`git log -1 --format=%an`
3. 置空：若以上均无法获取

## 版本号规则

- 有 Git：`1.{yy}.{Mdd}.{git提交次数}`
- 无 Git：`1.{yy}.{Mdd}.{hmm}`

字段约定：
- `{yy}`：年份后两位
- `{Mdd}`：月份不补零 + 日期补零
- `{git提交次数}`：`git rev-list --count HEAD`
- `{hmm}`：小时不补零 + 分钟补零

## 统一文档头

```markdown
# 文档标题

**项目名称**：XXX项目
**作者**：<作者>
**日期**：YYYY-MM-DD
**版本**：1.26.509.1234

## 变更日志

| 版本 | 日期 | 作者 | 变更内容 |
|------|------|------|----------|
| 1.26.509.1234 | YYYY-MM-DD | <作者> | 初始版本 |
```
