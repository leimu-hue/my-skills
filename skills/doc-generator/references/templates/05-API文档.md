### 2.1 取消审批发布并删除记录

**接口名称**：根据流程ID取消审批发布并删除发布记录

**描述**：审批发布之后，当用户未点击“暂存”或“提交”而直接返回（如关闭页面、点击取消等）时，调用此接口取消本次审批发布，并删除已生成的发布记录。

**URI**：/xp/bpa/workflow/canceled-wf-dh

**协议**：HTTPS

**请求方法**：POST

**请求参数（Query String）**：

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| wf_id | string | 是 | 流程实例ID | 2018201944915226624 |

**请求体（Body）**：无

**返回参数**：

| 属性 | 类型 | 说明 |
|------|------|------|
| success | boolean | 操作是否成功，true 表示成功，false 表示失败 |
| code | long | 业务响应码，0 表示成功，其他表示错误 |
| msg | string | 响应提示信息，成功时通常为空字符串 |

**响应码说明**：

| 响应码 | 说明 | 处理建议 |
|--------|------|----------|
| 0 | 成功 | - |
| -1 | 无效的流程ID | 检查 wf_id 是否为空或不存在 |
| -2 | 流程状态不允许取消 | 仅在未提交未暂存状态下可取消 |
| 500 | 系统内部错误 | 联系技术支持 |

**调用示例**：

```text
POST /xp/bpa/workflow/canceled-wf-dh?wf_id=2018201944915226624 HTTP/1.1
Host: api.example.com
```

**返回示例**：

```json
{
	"success": true,
	"code": 0,
	"msg": ""
}
```
