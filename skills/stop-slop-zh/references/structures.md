# 需要避开的结构（句子 / 段落 / 风格层面）

本文件汇集**句子、段落、风格层面**的 AI 痕迹。词、短语层面见 [phrases.md](phrases.md)，每个模式的改前／改后示例见 [examples.md](examples.md)。

## 一、二元对比

这种写法制造的戏剧感是假的。直接说。

| 套路 | 毛病 |
|------|------|
| "不是因为 X。而是因为 Y。" | 提前剧透的反转 |
| "问题不是 X，是 Y。" | 套路化的重新定义 |
| "答案不是 X，是 Y。" | 一眼看穿的转折 |
| "感觉像 X，其实是 Y。" | 铺垫加揭晓的老梗 |
| "问题不在 X，在 Y。" | 修辞上的绕弯 |
| "不是 X。但 Y。" / "不是 X，是 Y" | 机械对比 |
| "不是这个，是那个。" | 换汤不换药 |
| "不再 X，开始 Y" | 假转折 |
| "不是 X，其实是 Y" | 先否定再肯定的拐杖 |
| "关乎 X 而非 Y" | 假的区分 |
| "不只是 X，还有 Y" | 加料的含糊 |

**改法：** 直接说 Y。"问题是 Y。""Y 在这里才关键。" 把否定整个丢掉。

## 二、靠否定铺场（否定罗列）

还没说"是什么"，先罗列一堆"不是什么"。跟脱衣舞一样。

| 套路 | 毛病 |
|------|------|
| "不是 X……不是 Y……是 Z。" | 用否定吊胃口 |
| "那不是 X。那不是 Y。那是 Z。" | 同上，过去时 |

**改法：** 直接说 Z。读者不用你铺红毯。

## 三、戏剧化断句

用残句来强调，读着像硬拗出来的深刻。

| 套路 | 毛病 |
|------|------|
| "[名词]。就这些。这就是[那个东西]。" | 装简单 |
| "X。还有 Y。还有 Z。" | 断句耍酷 |
| "这解锁了什么。[一个词]。" | 硬造高潮 |

**改法：** 写完整句子。内容比包装重要。

## 四、修辞铺垫

这些在宣告洞见，不是在给洞见。

| 套路 | 毛病 |
|------|------|
| "如果……呢？" | 装苏格拉底 |
| "我的意思是：" | 多余的前情提要 |
| "想想看：" | 居高临下 |
| "这没关系。" | 多此一举的许可 |

**改法：** 把话说出来。让读者自己想。

## 五、公式化句式

| 套路 | 毛病 |
|------|------|
| "等到 X 时，我已经 Y 了。" | 叙事模板 |
| "不是 Y 的 X" | 绕弯。直接说 "X 坏了" |

## 六、虚假能动性

给没生命的东西安上人的动词。投诉不会"变成"修复。赌注不会"生死攸关"。决策不会"浮现"。得有人做了什么，这些才发生。AI 爱这么写，因为不用点名谁干的。

| 套路 | 毛病 |
|------|------|
| "投诉变成了修复" | 投诉什么都没干。是有人修好了。 |
| "赌注数日内生死" | 赌注没有寿命。是有人砍掉项目，或把它做出来。 |
| "决策浮现了" | 决策不会自己冒出来。是有人拍了板。 |
| "文化转变了" | 文化不会自己变。是人改了做法。 |
| "对话走向……" | 对话不会自己走。是有人带偏或带正。 |
| "数据告诉我们" | 数据就躺在那。是有人读了、下了结论。 |
| "市场奖赏……" | 市场不会发奖。是买家掏钱。 |

**改法：** 点出具体的人。"团队那周就修好了"胜过"投诉变成了修复。" 要是实在没有具体的人，就用"你"，把读者拉进现场。

## 七、旁白置身事外

飘在场景上空，不把读者带进去。

| 套路 | 毛病 |
|------|------|
| "没人为此设计过。" | 飘着的观察 |
| "这是因为……" | 说教腔 |
| "这就是为什么……" | 同上 |
| "人们往往……" | 键盘社会学家 |

**改法：** 把读者带进现场。"你不会某天坐下来说决定要……" 胜过 "没人为此设计过。"

## 八、被动语态

每句话都得有个主语在做事。被动语态藏起干活的人，泄气。

| 套路 | 改法 |
|------|------|
| "X 被创建了" | 谁建的，点名 |
| 隐去主语的"人们认为" | 谁这么认为，点名 |
| "出了错" | 谁出的错，点名 |
| "做出了决定" | 谁拍的板，点名 |

**改法：** 找出干活的人，放到句首。

## 九、句子别这么开头

| 套路 | 改法 |
|------|------|
| 以"为什么 / 何时 / 哪里 / 哪个 / 谁 / 怎么"起头 | 重写。让主语或动词打头。 |
| 段落以"所以"开头 | 用内容开头 |
| 句子以"看，"开头 | 删 |

用疑问词起头会变成拐杖。"让这事难的是……" 改成 "约束是……"，最好直接点出那个约束。

## 十、节奏

| 套路 | 改法 |
|------|------|
| 三件套罗列 | 用两点，或一点 |
| 问完马上答 | 让问题喘口气，或干脆删 |
| 每段都俏皮收尾 | 换着花样收 |
| 破折号（——） | 偶尔可用，但别滥用。多数情况换逗号或句号。 |
| 碎句堆砌 | 别把短促有力的句子叠一起 |
| "不总是。不完美。" | 拿安抚当含糊 |

## 十一、用词

| 套路 | 毛病 |
|------|------|
| 偷懒的极端词（每个、总是、从不、所有人、没人） | 假权威。用具体代替空泛断言。 |
| 所有副词（"真的""只是""事实上""真正地""老实说""简单地""实际上"） | 空泛强调。完整列表见 [phrases.md](phrases.md)。 |

## 十二、提纲式"挑战与展望"

**盯这些词：** 尽管面临若干挑战、尽管存在这些挑战、挑战与遗产、未来展望。

**问题：** 很多模型生成的文章会硬塞一段公式化的"挑战"结尾。

**示例见 [examples.md](examples.md) 的「模式 6」。**

## 十三、否定式排比

**问题：** "不仅是……更是……""这不只是……而是……"被用滥了。

**示例见 [examples.md](examples.md) 的「模式 9」。**

## 十四、三段式法则

**问题：** 模型硬把想法凑成三组，显得周全。

**示例见 [examples.md](examples.md) 的「模式 10」。**

## 十五、虚假范围

**问题：** 用"从 X 到 Y"，但 X、Y 不在一条有意义的尺度上。

**示例见 [examples.md](examples.md) 的「模式 12」。**

## 十六、破折号滥用

**问题：** 模型比人更爱用破折号（——），模仿"有力"的销售文案，动不动就甩一个。人偶尔用，但 AI 往往句句都用。改用逗号或句号，只在不改意思就别扭时保留极少数。

**示例见 [examples.md](examples.md) 的「模式 13」。**

> 注：破折号不是禁品，偶尔点缀是正常的人类写法；这里要治的是"滥用"。
