# 需要去掉的短语（短语 / 词层面）

本文件汇集**词、短语层面**的 AI 痕迹。句子 / 段落 / 风格层面的痕迹见 [structures.md](structures.md)，每个模式的改前／改后示例见 [examples.md](examples.md)。

## 一、清嗓式开场

这些"铺垫"统统删掉，直接说事。

- "关键是："
- "事情是这样的："
- "原因在于——"
- "令人不安的真相是"
- "事实证明"
- "真正的……是"
- "说清楚"
- "真相是，"
- "我再强调一次："
- "坦白讲"
- "咱们来聊聊"
- "我觉得有意思的是"
- "但问题来了"

凡是 "关键是 / 是这样的 / 原因在于" 这种，都是在正事之前清嗓子。删了，直接讲重点。

## 二、强调套路

这些话没有任何信息量，删。

- "到此为止。"
- "你细品。"
- "这很重要，因为"
- "别搞错"
- "这就是为什么重要"

## 三、商业黑话

换成大白话。

| 别用 | 改用 |
|------|------|
| 应对（挑战） | 处理、面对 |
| 拆解（分析） | 解释、审视 |
| 拥抱（不适） | 接受 |
| 格局、版图（背景） | 情况、领域 |
| 颠覆者、改变游戏规则 | 重大、重要 |
| 加码、加倍下注 | 投入、加大 |
| 深度挖掘（分析） | 分析、审视 |
| 退一步看 | 重新考虑 |
| 面向未来、往前走 | 接下来、今后 |
| 回头再聊 | 回到、重访 |
| 对齐、达成共识 | 一致、说好 |

## 四、副词

所有副词一律删。别用 "……地" 的修饰。别软化、别加料、别打太极。

常冒出来的：

- "真的"
- "只是"
- "字面上"
- "真正地"
- "老实说"
- "简单地"
- "实际上"
- "深深地"
- "确实"
- "从根本上"
- "本质上"
- "不可避免地"
- "有趣的是"
- "重要的是"
- "关键的是"

还有这些凑字数的：

- "其核心是"
- "在当今的……"
- "值得一提的是"
- "归根结底"
- "说到……"
- "在一个……的世界里"
- "现实是"

## 五、元评论（自说自话）

删掉那些对着自己说话的旁白。文章要往前走，别老宣告自己的结构。

- "提示："
- "反转："/"剧透："
- "你其实知道，但"
- "但那是另一篇的事"
- "这其实是特性，不是缺陷"
- "披着……的外衣"
- "本文其余部分将解释……"
- "让我带你过一遍……"
- "本节我们将……"
- "正如我们将看到的……"
- "我想探讨……"

## 六、假亲切

装出来的亲近或硬挤的真诚：

- "悄然渗入"
- "我保证"
- "它们确实存在，我保证"

## 七、告知而非展示

光喊某事很难、很重要，却拿不出证据：

- "这真的很难"
- "这才是领导力的真实模样"
- "这才是……的真实模样"
- "才真正重要"

## 八、空话结论

只喊重要、却说不出具体东西的句子，杀掉。

- "原因是结构性的"
- "影响是重大的"
- "这是最深层的问题"
- "赌注很高"
- "后果是真实的"

一句话如果只说某件事重要、深层、结构性，却没点出具体所指，删掉，或者换成具体的东西。

## 九、夸大意义、遗产和趋势

**盯这些词：** 作为/充当、标志着、见证了、是……的体现/证明/提醒、至关重要/关键性、凸显/彰显其重要性、反映了更广泛的、象征着其持续的、为……奠定基础、关键转折点、不断演变的格局、不可磨灭的印记、深深植根于。

**问题：** 模型爱给随便哪件事加一层"它代表了更宏大的主题"的评论，把重要性吹大。

**示例见 [examples.md](examples.md) 的「模式 1」。**

**问题：** 反复强调"被报道"，通常只列来源不给上下文。

**示例见 [examples.md](examples.md) 的「模式 2」。**

## 十一、以"——ing"收尾的肤浅分析

**盯这些词（句尾的现在分词）：** 突出/彰显……、确保……、反映/象征……、为……做出贡献、培养/促进……、涵盖……、展示……。

**问题：** 句尾挂个分词短语，假装有了深度。

**示例见 [examples.md](examples.md) 的「模式 3」。**

## 十二、宣传与广告腔

**盯这些词：** 拥有（夸张）、充满活力的、丰富的（比喻）、深刻的、增强、体现、致力于、自然之美、坐落于、开创性的、令人叹为观止的、必游之地、迷人的。

**问题：** 模型在"文化遗产"这类话题上尤其端不住，容易夸张。

## 十三、模糊归因

**盯这些词：** 行业报告显示、观察者指出、专家认为、一些批评者认为（实际很少给出处）。

**问题：** 把观点安给一个模糊的权威，不点名。

**示例见 [examples.md](examples.md) 的「模式 5」。**

## 十四、AI 高频词

**问题：** 这些词在 2023 年后的文本里密集出现，还爱扎堆。

## 二十、填充短语

- "为了实现这一目标" → "为了实现这一点"
- "由于下雨的事实" → "因为下雨"
- "在这个时间点" → "现在"
- "在您需要帮助的情况下" → "如果您需要帮助"
- "系统具有处理的能力" → "系统可以处理"
- "值得注意的是数据显示" → "数据显示"
